#  Temperature Converter 

Aplikasi konversi suhu yang dibangun dengan **Flutter**. Aplikasi ini memungkinkan pengguna untuk melakukan konversi antara empat satuan suhu utama (**Celsius, Fahrenheit, Kelvin, Reamur**) secara instan dengan antarmuka yang bersih dan interaktif.

##  Fitur Utama
* **Konversi Multi-Unit:** Mendukung konversi bolak-balik antar Celsius, Fahrenheit, Kelvin, dan Reamur.
* **UI Modern (Material 3):** Menggunakan standar desain terbaru dari Google dengan komponen yang melengkung (*rounded*) dan bersih.
* **Gradient Styling:** Tombol konversi kustom dengan gradasi warna linear (Indigo & Blue).
* **Animasi Halus:** Transisi perubahan angka hasil konversi menggunakan `AnimatedDefaultTextStyle`.
* **Input Pintar:** Pad nomor otomatis saat input ditekan untuk memudahkan pengguna.

## Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **Design:** Material 3
* **State Management:** StatefulWidget (setState)


Aplikasi ini menggunakan metode Normalisasi Celsius untuk efisiensi kode:

Input dari user dikonversi terlebih dahulu ke Celsius.

Nilai Celsius tersebut kemudian dikonversi ke Satuan Target.
